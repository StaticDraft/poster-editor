# 海报设计编辑器 - 已实现功能清单 (极简版)

本文档整理并总结了目前 **Poster Design Editor** 针对海报排版设计完整实现的各项产品能力与技术特性。本版本聚焦于本地高性能 2D 图形排版设计及运行态预览。

---

## 1. 编辑器画布与视口控制能力

*   **画布基础配置**：支持自定义画布尺寸宽度（Width）、高度（Height）、自定义背景色。
*   **视口缩放与平移 (Pan & Zoom)**：
    *   支持通过鼠标滚轮/触控板进行画布平移与任意比例无级缩放。
    *   提供快捷缩放工具：放大、缩小、重置缩放（100%）、自适应窗口（Fit Window）。
    *   安全属性：支持锁定平移、锁定缩放以保障排版的稳定性。
*   **双轴物理刻度尺 (Rulers)**：提供精密的横向（X轴）和纵向（Y轴）像素刻度尺，刻度尺刻度与数字随画布缩放比例自动重算、重绘，定位精准。
*   **迷你导航地图 (MiniMap)**：在画布右下角提供视口预览微缩地图，展示当前视口相对整体画布的位置，便于快速导航。
*   **右键上下文菜单 (Canvas Context Menu)**：支持右键唤出菜单执行撤销、重做、置顶、置底、删除操作。

---

## 2. 图元体系与外观配置

支持绘制高精度矢量图元（由 Leafer.js 高性能 Canvas 引擎渲染）：
*   **矩形图元 (Rect)**：支持自定义填充色、描边格式（颜色、粗细）、圆角半径（Corner Radius）、阴影模糊度与偏移。
*   **椭圆图元 (Ellipse)**：支持尺寸、旋转角度以及常规描边填充外观修改。
*   **文本图元 (Text)**：支持自定义文本内容的多行输入、字号、粗体 (Bold)、斜体 (Italic)、下划线 (Underline)、字距、行高、对齐方式以及多样艺术字体包。
*   **星形图元 (Star)**：标准的矢量多角星形对象。
*   **自定义路径 (Path)**：支持加载 SVG 矢量 UnitPath 数据渲染复杂形状，支持图元在水平（Flip H）和垂直（Flip V）方向进行镜像翻转。
*   **图片图元 (Image)**：支持本地图片及外链图片地址接入，可自由控制水平/垂直镜像翻转、以及包含（Contain）填充模式。

---

## 3. 图元编排与组织架构

*   **层级调整**：支持图元一键置于顶层（Bring to Front）以及置于底层（Send to Back）。
*   **对齐与分布工具**：
    *   支持多选图元进行左对齐、水平居中对齐、右对齐、顶对齐、垂直居中对齐、底对齐。
    *   支持多选图元进行水平等距分布（Distribute X）以及垂直等距分布（Distribute Y）。
*   **树形图层管理 (Layer Tree)**：
    *   左侧提供图层结构面板，深度绑定图元的 Z-Index 遮挡顺序。
    *   可以通过图层列表实现图元的锁定（Lock，不可拖动编辑）与隐藏（Hidden，画布不可见）。
    *   图层树节点点击与画布实体双向高亮同步。
*   **图元分组管理 (Grouping)**：
    *   支持多选图元一键成组（Group），分配统一的 GroupId，便于批量同步位移和选择。
    *   支持一键解组（Ungroup）。
    *   双击组内成员时，系统自动识别其所属组，并在编辑引擎中同时选中组内全部图元。

---

## 4. 项目场景与持久化

*   **场景列表**：支持多场景（多页面）分类存储与快捷加载，列出最近修改日期及缩略图预览。
*   **场景操作**：提供新建场景、重命名场景、复制克隆场景、物理删除场景功能。
*   **画板缩略图预览 (Canvas Thumbnail)**：自动从场景配置生成可视化预览卡片展示在场景列表中。
*   **自动保存机制 (Auto-Save)**：应用内置 1.5 秒防抖自动保存监听器。当用户在画布上进行图元拖拽、缩放、属性修改时，后台将在操作暂停后的 1.5 秒内自动保存场景至本地 LocalStorage，防丢失。
*   **文件菜单导出/导入**：
    *   **导出 JSON**：一键导出 JSON 配置文件（包含画布配置、所有 Elements 属性）。
    *   **本地暂存**：支持保存项目工程至浏览器专属缓存槽，并随时一键加载找回历史设计。

---

## 5. 时光旅行与快捷键系统

设计了严谨的命令历史记录栈，全面接管编辑器核心指令：
*   **撤销 (Undo)**：恢复至最近的一次历史指令节点。
*   **重做 (Redo)**：重新执行已被撤销的操作。
*   **键盘高效操作映射**：
    *   `Ctrl + Z`：撤销上一步操作。
    *   `Ctrl + Y` 或 `Ctrl + Shift + Z`：重做。
    *   `Ctrl + C`：后台复制选中图元到临时剪贴板。
    *   `Ctrl + V`：粘贴已复制图元，并自动带入向下/向右各偏移 20 像素的防遮挡处理。
    *   `Delete` 或 `Backspace`：删除选中项（包含防误删提示弹窗）。
    *   `Ctrl + S`：触发主动强制场景暂存与外部导出存档生成。

---

## 6. 运行与预览系统 (Preview Mode)

*   **沙盒隔离运行**：支持独立页签新开 Preview 窗口（路由为 `/preview`）。
*   **数据传递机制**：通过 LocalStorage 快照传递数据，零外部网络依赖下还原真实图形渲染。

---

## 7. 全局非功能特性与体验设计

*   **全局动态主题系统**：支持一键热切换深色模式（Dark Mode）与浅色模式（Light Mode），确保整体交互界面配色和谐。
*   **国际化多语言 (i18n)**：基于 `react-i18next` 规范化设计，完全抹平所有非 locales 文件下的中文字符硬编码，界面操作可在中文与英文之间秒级自由换算。
