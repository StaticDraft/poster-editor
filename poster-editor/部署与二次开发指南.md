## 1. 一键线上部署指南

### 方式 A：使用 Vercel 一键零成本部署 (推荐)
1. 将源码上传至你的 GitHub / Gitee 仓库。
2. 登录 [Vercel](https://vercel.com)，点击 **Add New Project**。
3. 选择你的仓库，Framework Preset 选择 **Vite**。
4. Build Command 保持为 `npm run build`，Output Directory 保持为 `dist`。
5. 点击 **Deploy**，约 1 分钟后即可获得公网可访问的 HTTPS 域名链接！

### 方式 B：Nginx 服务器传统部署
1. 在本地运行打包命令：
   ```bash
   npm run build
   ```
2. 打包完成后会生成 `dist/` 静态资源目录。
3. 将 `dist/` 目录上传至服务器（如 `/var/www/poster-editor`）。
4. 在 Nginx 配置文件 `nginx.conf` 中加入以下配置：
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;

       location / {
           root /var/www/poster-editor;
           index index.html;
           try_files $uri $uri/ /index.html;
       }
   }
   ```
5. 执行 `nginx -s reload` 刷新 Nginx 即可上线。

## 2. 如何新增自定义海报模板

项目模板存放在 `src/lib/presetTemplates.ts` 文件中。

### 步骤：
1. 打开 `src/lib/presetTemplates.ts`。
2. 在 `PRESET_TEMPLATES` 数组中追加新的模板对象：
   ```typescript
   {
     id: 'tpl-custom-01',
     categoryId: 'ecommerce', // 对应分类：ecommerce | invitation | guochao | recruitment | food
     categoryName: '电商促销',
     name: '自定义双十一海报',
     description: '高颜值大促海报模板',
     coverBg: 'linear-gradient(135deg, #1e3a8a 0%, #3b82f6 100%)',
     canvasConfig: {
       width: 800,
       height: 1200,
       bgColor: '#1e3a8a',
     },
     elements: [
       // 图元数组，可以在编辑器中设计好后导出 JSON 直接贴入
     ],
   }
   ```

## 3. 如何新增自定义字体

字体配置集中在 `src/core/fonts/fontList.ts` 文件中。

### 步骤：
1. 打开 `src/core/fonts/fontList.ts`。
2. 在 `FONT_LIST` 数组中添加新的字体配置项：
   ```typescript
   {
     family: 'Your Custom Font',
     displayName: '我的艺术字体',
     category: 'chinese', // 分类：sans | serif | handwriting | display | chinese
     source: 'google',
     sampleText: '海报文案预览',
   }
   ```
3. 系统会在用户选择该字体时，通过 `loadFont(family)` 自动动态从 Google Fonts 加载对应的 CSS 规则。

## 4. 如何对接后端 REST API 存储海报数据

目前项目采用 Zustand + localStorage 实现了纯前端多场景自动保存。若需接入 Java / Node.js / Python 后端服务保存海报工程：

### 步骤：
1. 在 `src/store/useEditorStore.ts` 中添加 API 异步方法：
   ```typescript
   saveToBackend: async () => {
     const { elements, canvasConfig, projectName } = get()
     const payload = { elements, canvasConfig, projectName }
     
     const res = await fetch('/api/posters/save', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify(payload)
     })
     return await res.json()
   }
   ```

## 5. 学生毕设/大作业答辩常见问题解析

### Q1: 为什么选择 Leafer.js 而不是 Fabric.js 或 原生 HTML5 Canvas？
> **答**：Leafer.js 是新一代极速 Canvas 2D 引擎，性能远高于传统 Fabric.js。它具备良好的树状节点管理、内存自动回收、高清 DPI 适配以及丰富的事件派发机制，能保证在包含数百个图元的大型海报设计中依然保持 60fps 的顺滑拖拽体验。

### Q2: 离屏导出是如何实现高清 3x 渲染的？
> **答**：项目在 `ExportModal.tsx` 中采用了虚拟离屏容器策略（Offscreen Container）。导出时不依赖当前屏幕 DOM 的显示尺寸，而是在后台隐式创建特定像素尺寸与 `pixelRatio`（倍率 1x/2x/3x）的临时 Leafer UI 实例，渲染完成后转为 Blob / Base64 并自动触发下载，随后销毁临时实例防止内存泄漏。

### Q3: 项目是如何保证多语言国际化不出现硬编码的？
> **答**：项目严格遵守国际化优先（i18n First）原则，使用 `i18next` 与 `react-i18next` 建立全局多语言管道，所有静态文本与动态提示均收录在 `src/locales/` 统一字典中，并通过自定义递归深合并机制（`deepMerge`）避免语言切换时的缺失与错乱。
