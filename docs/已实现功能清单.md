# 海报编辑器已实现核心功能清单 (全量完成)

本项目旨在打造极简、现代、高颜值且功能媲美 Canva / 稿定设计的专业海报在线设计编辑器。

---

## 🌟 核心功能一览表

### 1. 🎨 画布与交互引擎 (Leafer UI 高性能渲染)
- **精准标尺与吸附参考线**：双轴像素标尺，点击标尺边缘即可交互创建天蓝色 (`#06b6d4`) 纵横排版参考线。
- **智能中心与边缘磁吸对齐**：拖拽图元时自动计算邻近组件边缘/中心及画布中轴，实时渲染红色虚线对齐引导线。
- **完美自适应居中与缩放控制**：
  - 点击顶栏 **「自适应 (Fit to Window)」** 按钮一键自适应居中。
  - **双击鼠标中键** 快速触发视口自适应居中显示。
  - 优化滚轮中轴缩放步长 (`zoomSpeed: 0.02`)，滚轮缩放更加细腻平滑。
- **拖拽图片替换**：拖拽素材图片至画布已有图片组件上方即可完成无缝源图片替换。

---

### 2. 📚 素材库、多目录分类与图片压缩 (IndexedDB 本地存储)
- **多分类素材折叠目录 (Foldable Directories)**：
  - 支持用户自主建立多个分类目录（如 `默认素材分类`、`促销贴纸`、`品牌 logo`）。
  - 每个目录均可独立展开/折叠。
- **目录专属上传与画布压缩**：
  - 在素材库顶部显示当前选中目录，点击 **「导入素材」** 可将图片保存到该目录。
  - 利用 Canvas API 自动 downscale 压缩至 160px JPEG 轻量缩略图，大幅提升列表渲染性能；拖至画布时使用原图高保真渲染。
- **瀑布流无限加载 (Waterfall Infinite Scroll)**：
  - 目录展开后内部呈现 2 列瀑布流布局，向下滑动自动触发分页加载。

---

### 3. 🖼️ 多分类预置海报模板库与一键转场景
- **5 大精美模板业务大类**：
  - 🚀 **电商促销**：`618 狂欢年终大促`、`新品极简发售海报`
  - 盛典邀请**：`2026 年度设计盛典`、`赛博电音狂欢夜 Party`
  - 🏮 **国潮经典**：`国潮崛起 匠心造物`
  - 🎓 **招聘招募**：`加入我们 职等你来`
  - ☕ **餐饮美食**：`夏日冰爽饮品 买一送一`
- **侧边栏一级 Tab 级联**：
  - 将「模板」提升为左侧侧边栏第一级核心导航 Tab，与「组件」、「素材」、「图层」平级。
- **直接载入查看与右键「转为场景」**：
  - 点击模板卡片直接全量载入主画布进行交互预览与编辑。
  - 画布右键菜单提供 **「转为场景 (保存至页面目录)」** 选项，点击自动将模板转存为独立场景并跳转至「页面」目录。

---

### 4. 🔤 矢量图元、二维码/条码与属性编辑
- **1st-Class 可编辑动态二维码/条码**：
  - 支持拖拽添加 QRCode 与 Barcode 矢量物料。
  - 属性面板支持实时修改网址或文本，画布秒级生成更新矢量图形。
- **丰富的字体库与样式排版**：
  - 集成 30+ 款免费中英文艺术字体包。
  - 支持渐变填充 (Linear/Radial)、字号、字重、对齐方式、字间距、行高、描边与阴影。
- **图像滤镜Preset与镜像**：
  - 支持黑白、复古、模糊马赛克、高亮、高对比滤镜热切换。
  - 支持水平 (`flipH`) 与垂直 (`flipV`) 镜像翻转。

---

### 5. 导出与工程管理
- **多格式与多倍率导出**：支持选择 PNG, JPG, WebP 格式及 1x / 2x / 3x 高清放大导出。
- **工程导入导出**：支持 `.poster` 格式离线工程包打包与解包。
- **防抖自动保存**：1.5 秒自动同步保存 LocalStorage，实时 SaveStatus 状态勋章反馈。
