# 商业授权与素材版权说明

这份说明用于交付源码或成品时随包附带，避免买卖双方对授权范围、素材版权和售后边界产生误解。

## 源码授权范围

购买后，买家可以：

- 用于个人学习、课程设计、毕业设计、答辩演示。
- 在自己业务中二次开发和部署使用。
- 修改 UI、模板、图元、导出逻辑、打包方式。
- 作为外包项目基础继续开发交付给自己的客户。

未经额外书面授权，买家不可以：

- 将原始源码或轻微改名后的源码再次打包转卖。
- 声称自己是原始项目作者。
- 删除第三方依赖、字体、图片素材应保留的版权和许可证信息。
- 使用本项目从事违反平台规则或法律法规的业务。

## 第三方依赖说明

项目使用 React、Vite、TypeScript、Leafer、Electron、Tailwind CSS、Zustand、i18next 等第三方开源依赖。实际商用前，买家应根据自己的发布方式核验对应开源许可证要求。

## 图片和字体素材说明

项目中的模板图片和字体主要用于演示设计器能力。不同图片、字体和在线资源可能有独立授权条款。

建议买家在正式商用发布前：

- 替换为自己拥有版权或明确获得授权的品牌图、商品图和背景图。
- 核验在线图库图片的最新授权条款。
- 核验字体是否允许商用嵌入、分发或随软件打包。
- 不要直接使用未确认授权的品牌 Logo、人物肖像、IP 形象或受保护素材。

卖家可以协助说明项目结构和替换方式，但不对买家后续自行添加或使用的素材承担授权责任。

## 售后范围

基础售后包括：

- 协助买家安装依赖。
- 协助启动开发环境。
- 协助执行构建命令。
- 解释主要目录和二次开发入口。

以下内容属于额外定制：

- 新增登录、会员、支付、云存储、后端管理系统。
- 大量新增模板、字体、素材。
- 接入第三方 AI、抠图、商品接口、短信或微信生态。
- 修改成完整 SaaS 或多租户系统。
