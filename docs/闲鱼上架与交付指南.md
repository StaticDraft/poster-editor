# 闲鱼上架与交付指南

这份文档用于把 PosterCraft 包装成可成交的闲鱼商品。建议主卖方向是“React + Electron 海报编辑器源码 / 毕设大作业 / 可二开工具包”，不要只写成普通设计软件。

## 推荐商品定位

优先卖给这三类买家：

- 前端学生：毕业设计、课程设计、综合实训、大作业。
- 前端开发者：需要一套可运行、可二开的可视化编辑器源码。
- 小商家/运营：需要模板、二维码、批量生成和高清导出。

## 推荐定价

- 成品体验版：29-59 元，交付 Windows 可运行包和基础教程。
- 源码学习版：99-199 元，交付源码、运行教程、功能说明、答辩说明。
- 二开商用版：299-699 元，交付源码、部署指导、二开说明、一次安装协助。

价格不要只按代码量定，要按“买家拿到后能少踩多少坑”定。

## 详情页卖点顺序

详情页先讲结果，再讲技术：

1. 可视化拖拽海报编辑器，打开即可设计。
2. 内置多类海报模板，支持直接编辑和保存场景。
3. 支持素材目录库，可把 Logo、商品图、贴纸导入到指定目录。
4. 支持文字、图片、二维码、条形码、几何图形、图层管理。
5. 支持 PNG / JPG / WebP 高清导出。
6. 支持批量套打，一次生成多张不同文案、价格、二维码的海报。
7. 支持 Electron 桌面端打包，也支持 Vite 静态站点部署。
8. 交付源码、成品、教程、二开说明，适合毕设/课程设计/外包二开。

## 演示视频脚本

建议录一个 2-3 分钟视频：

1. 打开软件，展示主界面。
2. 切到模板，选择一张海报模板并载入。
3. 双击修改标题、价格、活动信息。
4. 添加二维码，修改二维码链接。
5. 切到素材，创建目录，导入 Logo / 商品图到当前目录。
6. 拖拽素材到画布。
7. 点击导出图片，选择 2x PNG。
8. 打开批量套打，改几组文案和二维码，一键生成多张。

视频里一定要展示“成品效果图”，不要只展示代码。

## 售后边界

建议提前写清楚：

- 包运行：协助解决安装依赖、启动、打包问题。
- 不包环境：电脑系统损坏、Node 环境混乱、网络无法下载依赖等需要买家配合。
- 不包定制：新增登录、支付、后端、会员、云存储等属于二开定制。
- 不包转卖：源码交付给买家学习和二开使用，不授权原样二次转卖。

## 上架前检查

- `npm run build` 可以通过。
- Windows 成品包可以打开。
- 素材目录可以创建、删除、导入图片、拖拽到画布。
- 模板可以载入、编辑、导出图片。
- 批量套打可以正常导出多张图片。
- README、功能清单、授权说明和实际功能一致。
