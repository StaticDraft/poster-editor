# 买家快速开始

## 1. 运行源码版

安装 Node.js 18 或更高版本后，在项目目录执行：

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址，一般是：

```text
http://localhost:5173/
```

## 2. 打包网页版本

```bash
npm run build
```

构建产物在 `dist/` 目录，可部署到 Vercel、Netlify、Nginx 或静态网站托管服务。

## 3. 打包 Windows 桌面版

```bash
npm run electron:build
```

构建产物在 `dist-electron/` 目录。桌面版基于 Electron，适合离线演示和交付小白买家。

## 4. 常用操作

- 新建海报：顶部文件菜单或页面目录中新建。
- 使用模板：左侧“模板”中选择模板并载入。
- 管理素材：左侧“素材”中创建目录，选择目录后点击“导入素材”。
- 添加元素：左侧“组件”拖拽文字、图片、二维码、图形到画布。
- 修改属性：选中画布元素后在右侧属性面板调整。
- 导出图片：顶部工具栏点击“导出图片”，选择格式和倍率。
- 批量生成：顶部工具栏点击“批量套打”，填写多组文案和二维码后导出。

## 5. 常见问题

### npm install 很慢怎么办？

可切换国内镜像：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 启动后页面空白怎么办？

先确认依赖安装完成，再执行：

```bash
npm run build
```

如果构建报错，把终端错误截图发给卖家定位。

### 图片导入后在哪里？

进入左侧“素材”，先点击目标目录，再点击“导入素材”。导入成功后图片会保存在当前目录中，可拖拽到画布。

### 可以二次开发吗？

可以。项目基于 React、TypeScript、Vite、Zustand 和 Leafer Canvas，主要功能模块集中在 `src/components`、`src/core`、`src/store`、`src/lib`。
